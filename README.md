# OpenRUM

OpenRUM is an open-source, self-hosted real user monitoring platform for
front-end errors, performance, API requests, and user behavior.

The project is currently in the planning and foundation stage. Start with:

- `docs/product-vision.md` — product strategy and scope
- `docs/prd.md` — implementation specification
- `docs/product-roadmap.md` — phased build plan and task tracker

## Planned stack

- React, TypeScript, and Vite
- Go
- ClickHouse and PostgreSQL
- Kafka and Redis
- Alibaba Cloud OSS
- Kubernetes

## Status

See `docs/product-roadmap.md`. Development begins with Phase 0.
