OpenRUM is an open-source, self-hosted frontend monitoring platform. You run an **Instance** on your own infrastructure, add the Browser SDK to a web application, and investigate user behavior, errors, performance and API requests in the **Console**. Telemetry never leaves infrastructure you operate.

It is built around one investigation path: start from a change in behavior or a failed Session, follow it to the **Issue** behind it, and reach the stack frame that needs a fix, without copying IDs between tools.

## What it covers

| Capability               | What you get                                                                                         | Read                                                                  |
| ------------------------ | ---------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| Errors and investigation | JavaScript errors grouped into Issues, optional Source Map frames, the Session timeline around each. | [Investigate an issue](/docs/product/investigation/)                  |
| Performance and APIs     | Core Web Vitals, route performance, request latency and failures.                                    | [Performance](/docs/product/performance/)                             |
| Behavior analytics       | Page Views, visitors, Custom Events, funnels, paths and retention.                                   | [Behavior analytics](/docs/product/analytics/)                        |
| Logs                     | Structured browser logs searchable by severity, user and Session.                                    | [Logs](/docs/product/logs/)                                           |
| Dashboards and alerts    | Project dashboards and metric alerts delivered to Feishu/Lark or a Webhook.                          | [Alerts](/docs/product/alerts/)                                       |
| Privacy by default       | No raw input values, request or response bodies or headers in automatic capture.                     | [Privacy](/docs/self-hosting/security/privacy/)                       |

## What runs

An Instance has five application services: the Console web server, API, Ingest, Consumer and Worker. They use four required dependencies, PostgreSQL for accounts, projects and settings, ClickHouse for events and analysis queries, Kafka as the ingestion buffer, and Redis for caching and rate limits. Object storage is optional and only needed for Source Map uploads. [Architecture](/docs/self-hosting/architecture/) shows how an event moves through them.

<Aside type="caution" title="Alpha stage">
  OpenRUM is Alpha. Expect schema and API changes before the first stable release, and complete the
  deployment guide's capacity, backup and access checks before accepting production traffic. Local
  benchmark results are not production capacity guarantees.
</Aside>
