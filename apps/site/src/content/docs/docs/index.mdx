## Before you expose an Instance

OpenRUM is Alpha. Read the [threat model](/docs/self-hosting/security/threat-model/) and
[capacity planning](/docs/self-hosting/capacity/), and verify capacity with your actual workload. Published local single-host benchmarks are not production capacity guarantees.

Documentation is available in English and Chinese. Use the language selector in the header to switch.
