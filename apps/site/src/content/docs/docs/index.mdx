OpenRUM is an open-source, self-hosted frontend monitoring platform. It helps you understand user behavior and quickly identify, diagnose, and resolve production issues. Documentation applies to **Alpha / main** unless a page says otherwise.

For local evaluation, use the deterministic Demo. For production, read Self-hosting, Operations, Security and the benchmark limitations before exposing an Instance.
