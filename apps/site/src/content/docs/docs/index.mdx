## Before you expose an Instance

OpenRUM is Alpha. Read the [threat model](/docs/self-hosting/security/threat-model/) and the
[measured capacity limits](/docs/self-hosting/capacity/) first: the published benchmark is a
local single-host rehearsal that OpenRUM did not pass at its target rate, and no production
capacity claim is made from it.
