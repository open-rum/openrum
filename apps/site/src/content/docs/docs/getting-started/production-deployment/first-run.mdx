Complete [Install services](/docs/getting-started/production-deployment/install/), confirm service readiness and have the bootstrap token ready.

<Steps>

1. ## Create the first administrator

   Open `https://rum.example.com/setup` and fill in:

   1. Organization name.
   2. Your display name and work email.
   3. A password of at least 12 characters, and its confirmation.
   4. The Bootstrap Token saved in the credentials step.
   5. Submit the initialization form.

   Helm production deployment does not seed local demo accounts. This entry closes after initialization; use the created account for subsequent logins. If the Instance is already initialized, sign in with an existing administrator account.

   **Success:** You are signed into the Console and can access your Organization.

1. ## Connect the first real Project

   Follow [Create your first project](/docs/getting-started/create-first-project/): select the SDK platform, configure the application origin and `production` Environment, copy the onboarding DSN and initialize the SDK.

   After deploying the application, visit a page and send a test Event. Select the same Project, `production` and the last 15 minutes in the Console, then find the Event and its Session.

   **Success:** Telemetry has passed through Ingest, Kafka and Consumer and is queryable. If not, check origin, DSN, Environment and time range before pipeline logs.

</Steps>
