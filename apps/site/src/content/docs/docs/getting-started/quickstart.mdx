OpenRUM is an open-source, self-hosted frontend monitoring platform. You run an **Instance** and connect applications through the Browser SDK. The **Console** lets you investigate behavior, errors, performance and API requests.

Each guide follows preparation, startup, login and verification. Commands run from the repository root unless a step says otherwise.

Already have a running Instance? Go directly to [Create your first project](/docs/getting-started/create-first-project/).

## What gets installed

OpenRUM runs five application services: the Console web server, API, Ingest, Consumer and Worker. They use four required dependencies:

| Dependency | In plain language                                       |
| ---------- | ------------------------------------------------------- |
| PostgreSQL | Stores accounts, projects, settings and workflow state  |
| ClickHouse | Stores monitoring events and serves analysis queries    |
| Kafka      | Buffers accepted telemetry before it reaches ClickHouse |
| Redis      | Supports caching, rate limits and short-lived state     |

Local development starts these dependencies for you. Production deployment requires you to prepare them first.

**Object storage is optional.** You can use the core monitoring features without a Bucket. Configure OSS or S3-compatible storage when you need Source Map uploads to resolve minified stack traces.

## What success looks like

By the end of either guide you can sign in, create a Project, copy its DSN, send an event from an application, and find that event and its Session in the Console.
