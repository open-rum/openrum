**Applies to:** Alpha. Status: Alpha implemented.

Performance views explain why a journey felt slow or unstable.

## What OpenRUM captures

- Core Web Vitals such as LCP, INP and CLS from real Page Views
- Route-level performance context for client-side navigation
- Browser API Request timing that often correlates with UX regressions

## How to use it

1. Compare Web Vitals across Release, device or country segments.
2. Open affected Sessions when a Route regresses.
3. Correlate slow or failing API Requests with Issue spikes.

Performance metrics are evidence for investigation, not a separate product. Related: [Investigation](/docs/product/investigation/), [API monitoring](/docs/product/api-monitoring/).
