**Applies to:** Alpha / main. Status: Alpha implemented.

Analysis answers what users did across a Project and Environment.

## Core views

- **PV / UV** over time with country, device and browser breakdowns
- **Acquisition** and traffic context for monitored Origins
- **Custom Events** with governed names, attributes and measurements
- **Funnels** and bounded paths for conversion investigation
- **Weekly retention** based on anonymous visitor IDs

## Investigation tips

- Always constrain time range and cardinality before drilling into Sessions.
- Use a funnel or Route filter to select candidate Sessions instead of scanning raw Events.
- Treat Custom Events as product milestones, not free-form logs.
