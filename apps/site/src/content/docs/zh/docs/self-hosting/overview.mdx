## 自部署意味着什么

你的团队需要负责域名与 HTTPS、凭据、容量、服务健康、升级和故障恢复。先了解[架构](/zh/docs/self-hosting/architecture/)与[外部依赖](/zh/docs/self-hosting/dependencies/)，再安排：

- 接入真实流量前的[容量与保留规划](/zh/docs/self-hosting/capacity/)。
- 首次升级前的[备份与恢复演练](/zh/docs/self-hosting/backup-restore/)。
- 启用 Google、GitHub、OIDC 或 LDAP 登录时的[控制台认证配置](/zh/docs/self-hosting/authentication/)。
- 日常[升级](/zh/docs/self-hosting/upgrades/)、[存储压力处理](/zh/docs/self-hosting/storage-pressure/)与[故障排查](/zh/docs/self-hosting/troubleshooting/)。
- 将 Ingest 暴露到公网前阅读[威胁模型](/zh/docs/self-hosting/security/threat-model/)。

对象存储是可选的：没有 Bucket 时核心监控仍能运行；Source Map Artifact 需要 Alibaba OSS 或 S3 兼容服务。
