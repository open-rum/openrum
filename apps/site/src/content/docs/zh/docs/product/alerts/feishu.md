---
title: 接入飞书
description: 接入飞书（或 Lark）群机器人，让告警以卡片形式发到群里，并带回控制台的诊断链接。
appliesTo: Alpha
---

告警会以卡片形式发到群里，卡片上有项目、环境、指标、当前值、阈值和统计窗口，以及一个「进入诊断」按钮。

## 1. 在群里添加自定义机器人

1. 在飞书群里打开「设置 → 群机器人 → 添加机器人 → 自定义机器人」。
2. 给机器人起个名字，比如「OpenRUM」，复制它的 **Webhook 地址**，形如 `https://open.feishu.cn/open-apis/bot/v2/hook/…`。Lark 的 `open.larksuite.com` 地址同样可用。
3. 在安全设置里开启**签名校验**并复制密钥。这一步可选，但推荐开启。
4. 如果你更想用**自定义关键词**，填 `OpenRUM`。每张卡片的标题都包含它。

请把 Webhook 地址当作密钥保管：拿到它的人都能往群里发消息。

## 2. 在 OpenRUM 里添加渠道

1. 打开「设置 → 通知渠道」，选择「飞书」。需要组织的 Owner 或 Admin 权限。
2. 填写团队能认出来的名称、Webhook 地址和签名密钥。
3. 保持「保存后发送一条测试消息」开启，然后保存。群里应该会收到一张蓝色的测试卡片。

以后编辑渠道时，地址或密钥留空表示沿用已保存的值。

## 3. 在规则里使用

打开项目的「告警」页面，新建或编辑规则，在「通知渠道」里选中这个渠道。规则触发时，群里会收到一张红色的告警卡片。

## 收不到消息时

渠道列表和通知记录会显示发送失败的原因：

| 原因           | 处理方法                                                                                          |
| -------------- | ------------------------------------------------------------------------------------------------- |
| 签名校验失败   | OpenRUM 里的签名密钥和机器人的不一致，重新复制一次                                                |
| 消息不含关键词 | 把机器人的自定义关键词设为 `OpenRUM`                                                              |
| IP 不在白名单  | 机器人开启了 IP 白名单，加入 OpenRUM 服务器的出口 IP                                              |
| 触发频率限制   | 飞书每个机器人每分钟最多接收 100 条消息。OpenRUM 会稍后重试，也请减少过于频繁的规则或加长冷却时间 |
| 地址不安全     | 飞书渠道只接受飞书和 Lark 机器人地址                                                              |
| 未配置主密钥   | worker 需要 `OPENRUM_MASTER_KEY` 才能解密渠道配置                                                 |
