---
title: 告警
description: 用规则监控项目的错误、API 和性能指标，超过阈值时通知到飞书群或你自己的服务。
---

**适用版本：** Alpha。状态：Alpha 已实现。

一条告警规则监控项目的一个指标。指标超过阈值时，OpenRUM 会记录这次触发，通知规则选择的渠道，并附上能解释它的页面链接。

## 创建规则

在项目导航里打开「告警」，选择「新建规则」，或者从模板开始。模板只会预填编辑器，点击「创建规则」之前什么都不会保存。

| 设置     | 含义                                               |
| -------- | -------------------------------------------------- |
| 指标     | 错误数、错误率、API 失败率或 LCP P75               |
| 触发条件 | 达到（≥）或超过（>）阈值，单位跟随指标             |
| 统计窗口 | 5、10、15、30 或 60 分钟。每个窗口结束后评估一次。 |
| 环境     | 某一个环境，或全部环境                             |
| 冷却时间 | 发出通知后，同一条规则在这段时间内不再通知         |
| 通知渠道 | 通知发到哪里。不选渠道时，触发只记录在控制台。     |

保存前，编辑器会用一句话概括规则，例如：「当 production 环境最近 5 分钟错误率 ≥ 2% 时，通知 飞书·前端值班群。」

- 错误率是错误数除以页面浏览量，可能超过 100%。
- API 失败指网络失败和 5xx 响应，4xx 不算失败。
- 成员、Admin 和 Owner 可以管理规则，只读成员可以查看。

## 通知记录

「通知记录」Tab 列出每次触发的数值、阈值和处理结果：

| 状态       | 含义                                         |
| ---------- | -------------------------------------------- |
| 已送达     | 所有渠道都接收了通知                         |
| 部分失败   | 有渠道发送失败，把鼠标移到渠道上可以看到原因 |
| 发送失败   | 没有渠道接收成功，OpenRUM 最多重试 3 次      |
| 未配置渠道 | 规则触发时没有选择渠道                       |
| 冷却中     | 规则最近已经通知过，这次触发没有再发送       |

「进入诊断」会打开对应时间窗口和环境下的错误、API 或性能页面。

## 通知渠道

渠道属于组织，组织内所有项目的规则都可以使用。Owner 和 Admin 在「设置 → 通知渠道」里管理渠道。

| 渠道                                        | 状态                                   |
| ------------------------------------------- | -------------------------------------- |
| [飞书](/zh/docs/product/alerts/feishu/)     | 已支持：以卡片消息发到群聊             |
| [Webhook](/zh/docs/product/alerts/webhook/) | 已支持：向你的 HTTPS 服务发送签名 JSON |
| 钉钉、企业微信、Slack、邮件                 | 即将支持，界面上可见但暂不可选         |

每个渠道都可以发送测试消息。渠道地址和密钥用实例主密钥加密保存，接口不会返回明文，所以 API 和 worker 都需要配置 `OPENRUM_ALLOW_MANAGED_SECRETS` 与 `OPENRUM_MASTER_KEY`。目标地址必须是公网 HTTPS 地址，内网和私有地址会被拒绝。参见[威胁模型](/zh/docs/self-hosting/security/threat-model/)。
