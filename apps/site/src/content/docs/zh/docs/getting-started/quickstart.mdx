OpenRUM 是开源、可自托管的前端监控平台。你需要先运行一套 **OpenRUM 实例**，再通过 Browser SDK 接入自己的应用，就能在**控制台**查看用户行为、错误、性能和 API 请求。

## 会安装哪些服务

OpenRUM 包含控制台 Web 服务、API、Ingest、Consumer 和 Worker 五个应用服务，并使用四个必需依赖：

| 依赖       | 可以理解为                             |
| ---------- | -------------------------------------- |
| PostgreSQL | 保存账号、项目、设置和处理状态的数据库 |
| ClickHouse | 保存监控事件、提供分析查询的数据库     |
| Kafka      | 暂存已接收数据，等待后续写入的消息队列 |
| Redis      | 提供缓存、限流和短期状态的服务         |

本地开发命令会自动启动这些依赖；生产部署需要提前准备好。

**对象存储是可选的。** 没有存储桶也能使用核心监控功能。需要上传 Source Map、把压缩后的错误堆栈还原成源码时，再配置 OSS 或 S3 兼容存储。

## 完成后应该看到什么

你可以登录控制台，创建项目并复制 DSN，从自己的应用发送事件，然后在控制台找到该事件和对应会话。
