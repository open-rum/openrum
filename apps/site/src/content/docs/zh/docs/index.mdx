OpenRUM 是一款开源、可自部署的高性能前端监控平台，专为生产环境下的高吞吐与稳定运行设计。部署实例并接入 Browser SDK 后，即可在控制台统一观测错误、性能、API 请求、日志与用户行为。

## 核心能力

| 能力         | 你能得到什么                                                                         | 阅读                                            |
| ------------ | ------------------------------------------------------------------------------------ | ----------------------------------------------- |
| 错误与排查   | 按 Issue 聚合 JavaScript 错误，支持 Source Map 堆栈还原，以及错误前后的会话时间线。  | [排查线上问题](/zh/docs/product/investigation/) |
| 性能与 API   | Core Web Vitals、路由性能、接口请求延迟与失败监控。                                  | [性能](/zh/docs/product/performance/)           |
| 行为分析     | 页面浏览、访客、自定义事件、漏斗、路径与留存分析。                                   | [行为分析](/zh/docs/product/analytics/)         |
| 日志         | 可按级别、用户和会话检索的结构化浏览器日志。                                         | [日志](/zh/docs/product/logs/)                  |
| 仪表盘与告警 | 项目仪表盘，以及发送到飞书/Lark 或 Webhook 的指标告警。                              | [告警](/zh/docs/product/alerts/)                |
| 默认保护隐私 | 自动采集不含原始输入值、请求头和请求/响应体；头和内容仅在项目为指定 API 开启后记录。 | [隐私](/zh/docs/self-hosting/security/privacy/) |

## 运行时架构

一套实例包含五个应用服务：控制台 Web 服务、API、Ingest、Consumer 和 Worker；底层使用四个必需依赖：PostgreSQL 保存账号、项目和设置，ClickHouse 保存事件并提供分析查询，Kafka 作为接收缓冲，Redis 提供缓存和限流。对象存储为可选项，仅在上传 Source Map 时需要。完整的事件流转见[架构](/zh/docs/self-hosting/architecture/)。

<Aside type="caution" title="Alpha 阶段">
  OpenRUM 目前处于 Alpha 阶段，第一个稳定版本发布前，schema 和 API 都可能变化。对外暴露生产实例前，请先阅读[威胁模型](/zh/docs/self-hosting/security/threat-model/)与[容量规划](/zh/docs/self-hosting/capacity/)，并完成备份与访问检查。已发布的单机基准数据不代表生产容量保证。
</Aside>
