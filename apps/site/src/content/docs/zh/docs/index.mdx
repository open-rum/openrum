## 对外暴露实例之前

OpenRUM 处于 Alpha。先读[威胁模型](/zh/docs/self-hosting/security/threat-model/)和
[实测容量上限](/zh/docs/self-hosting/capacity/)：已发布的基准是一次本地单机压测，
OpenRUM 在目标速率上并没有通过，我们不会据此给出任何生产容量结论。
