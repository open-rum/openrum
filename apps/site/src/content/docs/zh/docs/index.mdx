## 对外暴露实例之前

OpenRUM 处于 Alpha。先读[威胁模型](/zh/docs/self-hosting/security/threat-model/)和
[容量规划](/zh/docs/self-hosting/capacity/)，使用自己的实际负载验证容量。已发布的本地单机基准不代表生产容量保证。
